CMR2005Launcher.exe <version>: plays your own copy of Colin McRae Rally 2005 on modern Windows and Linux.

Usage: CMR2005Launcher.exe [options]

Without options the settings window opens; Play saves them and starts the game.

Options (each is also a launcher.cfg key):
  --game <folder>                        Game folder
  --look original|widescreen|steam_deck  Look
  --resolution <WxH>                     Resolution
  --fps-limit <0-1000>                   Frame-rate cap
  --vsync on|off                         VSync
  --advanced-particles on|off            Advanced particles
  --wheel auto|on|off                    Wheel support
  --wheel-device <guid>                  Wheel
  --wheel-pedals <guid>                  Pedals
  --wheel-lock 180|270|360|540|900|full  Steering lock
  --wheel-deadzone <0-25>                Deadzone
  --wheel-curve <0-100>                  Curve
  --wheel-invert-throttle on|off         Invert throttle
  --wheel-invert-brake on|off            Invert brake
  --wheel-ffb <0-100>                    FFB strength
  --wheel-ffb-invert on|off              Reverse force feedback
  --wheel-log on|off                     Wheel log
  --runtime <folder>                     Private copy folder

Launcher switches:
  --settings   only the settings window (exit 0 after Play, 3 when closed)
  --no-window  play with the saved settings and these options, no window
  --check      check the game folder and its edition, then exit (see launcher.log)
  --linux      started by the Linux helper (linux/cmr2005-play)
  --help       this text
